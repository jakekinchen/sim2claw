# OR114: persistent static boundary-line identifiability

OR114 identifies one recurring physical-only image-space line family in the
eleven immutable OR97 occupancy maps. Development selects one orientation bin;
the same family clears the frozen support gates on positions `8-11` without
refit.

The numeric result does not identify an enclosure plane. The audit montage
shows the selected diagonal terminating in a bounded loop-like component across
episodes, which is incompatible with promoting it directly as an unbounded
wall or table seam. OR114 therefore accepts only persistent line-family
identifiability and routes the next card to deterministic endpoint/topology
attribution before any renderer-native primitive is fit.
