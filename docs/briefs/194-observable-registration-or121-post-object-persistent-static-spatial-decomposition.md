# OR121: post-object persistent-static spatial decomposition

OR121 reads only OR120B's eleven hash-bound eight-panel maps. A frozen `9/11`
physical-only-persistent consensus contains `911` pixels, with every episode
covering at least `98.35%` of that consensus. The largest component after the
inherited `3 px` tolerance-scale dilation occupies `38.02%` of support and is
clipped by the image bottom.

The inherited OR114 Hough extractor finds `50°` and `140°` line families with
`203.66 px` and `81.64 px` support, exactly `90°` apart. The selected family is
therefore a clipped image-space rectilinear planar array.

This does not name a keyboard, wall, enclosure, or other physical object, and
does not calibrate metric 3D geometry. Freeze a renderer-native planar-array
reconstruction next; same-video semantics, prediction, physics, event parity,
transfer, and promotion remain false.
