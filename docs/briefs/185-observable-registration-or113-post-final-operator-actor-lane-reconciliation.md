# OR113: operator actor lane reconciliation

OR113 is receipt-only. It continues actor work only if OR110 or OR112 passed
their material edge gates; neither a visual impression nor an appearance-only
gain is sufficient. If the actor lane closes, it compares the frozen OR97
persistent-static and dynamic gaps to the `0.6` outside-board target, then checks
whether OR99/OR100 already supplied a material renderer-native static primitive.

The decision tree selects exactly one next residual family. It cannot read a
pixel, decode video, render, fit, replay, change a threshold, reopen OR50/OR67,
or promote a simulator result.
