# OR75 frozen-camera development residual attribution

OR75 uses only the closed OR73/OR74 closeouts and OR74 receipt to select the next mechanism.
It compares every remaining metric gap, the static-to-temporal behavior, the
episode and phase spreads, and the edge change between search and final
evaluator resolution.

The frozen rule selects renderer structure before timing or appearance when
motion already passes, edge fails in both the static and full-timeline evidence,
and the edge gap exceeds the average-pixel gap. This ordering prevents a global
color response from cosmetically clearing the mean while the geometric edge
gate remains open.

The card emits JSON only. It decodes no video, renders no frame, fits no
parameter, creates no candidate, and keeps validation and evaluator-heldout
roles closed. Its result is mechanism attribution, not new visual, physical,
physics, promotion, or transfer evidence.
