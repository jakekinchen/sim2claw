# OR115: persistent linear workcell object attribution

OR115 applies one frozen connected-component rule to the OR114-selected line
support in the eleven immutable OR97 physical-persistent panels. All seven
development-supported rows and all three validation-supported rows resolve to
one finite, interior, elongated component. None resolve as a scene boundary.

The result authorizes a renderer-native finite linear primitive family. It does
not identify the object, calibrate metric geometry, or establish a same-video,
physics, prediction, transfer, or promotion result.
