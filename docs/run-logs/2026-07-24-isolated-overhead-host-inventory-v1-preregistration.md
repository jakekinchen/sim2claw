# Isolated Overhead Host Inventory v1 Preregistration

Date: 2026-07-24

Baseline: `40e59f000d0588fc36780694c57046d0d157f2e7`

The same-Mac common-session family is terminal degraded and exhausted. This
new transaction freezes the smallest next architectural gate before any SSH
connection or implementation: one zero-session metadata inventory of
`kelly@silicon.local`.

The proposed split keeps the D405 and robot path on `kelly-claude` and assigns
the fixed C922 overhead role to the separate Silicon host. The inventory may
read only host, macOS, camera, and USB metadata with three fixed system
programs. It may not read the remote repo, write a remote file, open a camera,
capture a frame, retry, or claim a live endpoint, clock alignment,
synchronization, metric depth, calibration, simulator improvement, or task
success.

The evaluator requires exactly one C922 USB `1133:2140` and zero D405 USB
`32902:2907` matches on Silicon. An absent C922 produces an explicit physical
attachment prerequisite rather than substitution or another camera family.

Budget before implementation is zero of one remote inventories and zero SSH
connections, sessions, frames, remote writes, robot motions, simulator
replays, or provider calls.
